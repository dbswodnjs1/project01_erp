
# Chicken ERP (JSP)

프랜차이즈 치킨 매장의 본사/지점을 관리하는 웹 ERP 시스템입니다.  
직원·지점 정보, 메뉴, 매출 등을 관리하며, 이 중 **사용자 정보·비밀번호·프로필 관리 기능**을 담당했습니다.

> Team Project / JSP 기반 ERP, 회원 정보 관리 모듈 담당

-----------------------------------------------------------------------------------------------------------------------

## 🔧 Tech Stack

- Java, JSP/Servlet
- Oracle DB
- JDBC, DBCP
- Apache Tomcat 10.1
- Bootstrap

---

## 주요 기능 (담당 영역)

### 1. 로그인 사용자의 비밀번호 변경
- 로그인 상태에서 기존 비밀번호·새 비밀번호 입력
- `BCrypt`를 이용해 DB에 저장된 해시값과 비교
- 검증 성공 시 새 비밀번호를 해시로 저장
- 변경 후 세션 만료 처리 및 재로그인 유도

### 2. 프로필 이미지 수정
- 마이페이지에서 프로필 이미지 업로드
- 서버 지정 디렉토리에 파일 저장 후, 파일 경로를 DB에 업데이트


### 3. 기본 정보 수정 화면
- 이름, 연락처, 주소 등 기본 정보 수정 폼
